# ADR-16: GUI를 기본 관리 입구로, 콘솔은 실행 파일에 넣은 Svelte 앱으로

- 날짜: 2026-09-24
- 상태: 채택. 이전 서버 렌더 GUI 결정을 대체하며 모든 표면이 Application Action만 호출한다는 계약은 유지한다.
- 관련 문서: [관리 GUI](../admin-gui-ia.md), [브랜드 에셋](../brand-assets.md)

## 결정

1. **관리의 기본 입구는 GUI다.** 일상 관리는 CLI·설정 파일 편집·DB 조작 없이 끝난다. CLI는 자동화·비상 복구용으로 남긴다.
2. **아이콘 한 번 클릭**: 실행 파일(`masamong open`, macOS `Masamong.app`)이 데이터 폴더의 데몬을 찾아 재사용하거나 백그라운드로 시작하고, 준비되면 기본 브라우저를 **1회용 로그인 링크**로 연다. 브라우저를 닫아도 봇은 계속 돈다. 데이터 폴더당 데몬은 하나(`daemon.lock`), 주소는 `daemon.json`에 기록한다. 기본 포트가 막히면 빈 loopback 포트를 쓴다.
3. **원격은 SSH**: 관리 화면은 loopback에만 열린다. `masamong connect user@host` 구현은 원격 데몬을 켜거나 재사용하고 SSH 포워딩 뒤 로컬 브라우저로 1회용 링크를 연다. Mac→SSH→Ubuntu headless 관리 화면 왕복과 1회용 링크 재사용 차단은 2026-09-24에 검증했다.
4. **콘솔 기술**: Svelte 5 + Vite + TypeScript로 만든 SPA를 빌드해 `internal/transport/web/ui/dist`에 커밋하고 `go:embed`로 실행 파일에 넣는다. 실행에 Node가 필요 없다. 서버는 JSON API(`/api/*`)로 Action만 부른다.
5. **성능 예산**을 빌드가 강제한다(`ui/scripts/postbuild.mjs`): 첫 로드 JS+CSS gzip 150 KiB 이하, 페이지별 조각 60 KiB 이하. 파일은 빌드 때 brotli/gzip으로 미리 압축하고 해시 파일은 영구 캐시한다. 2026-09-24 운영 UX 보강 후 첫 로드 54.4 KiB.
6. **비상 화면 `/lite`**: JavaScript 없이 상태·전체 일시 중지·재시작·로그인만 하는 서버 렌더 페이지를 남긴다.
7. **문구**: 완전 번역인 콘솔 문구(한국어·영어·일본어·중국어(간체)·스페인어)는 `locales/ui/*.json`에 둔다(한국어·영어 원본은 `ui/scripts/strings.py`). 다른 언어는 `locales/ui/<BCP-47>.json` 파일만 추가하면 서버와 선택기가 자동 발견하고, 빠진 키는 영어로 대체한다. 빌드는 모든 번들의 키·값·placeholder를 검사하며 RTL 언어는 문서 방향도 바꾼다.

## 이유

- 방·기억·도구·예산처럼 서로 얽힌 설정을 명령 인자로 관리하면 실효값과 영향이 보이지 않는다. GUI는 한 화면에서 대조·미리보기·되돌리기를 한다.
- 분할 보기, ⌘K, 실험실 비교, 실시간 갱신처럼 상호작용이 많은 화면은 서버 렌더 + htmx로 만들면 복잡도가 커진다. Svelte는 런타임이 거의 없어 저사양 기기에서도 가볍고(React 대비 기본 크기 약 1/10), 빌드 결과를 실행 파일에 넣으면 배포는 여전히 파일 하나다.
- 서버 쪽 부담은 오히려 준다: 서버는 화면을 그리지 않고 JSON만 보낸다.

## 결과

- 예전 서버 렌더 콘솔(템플릿·htmx)은 현재 구현에서 제거했다. 제품 관리 화면은 `ui/`의 Svelte SPA이며 `/lite` 비상 화면은 유지한다.
- `admin.web.enabled` 기본값은 true다. 설정 전(인스턴스 없음)에도 초기 설정 마법사를 위해 콘솔이 열린다. 기존 설정이 false여도 런처는 `--web`으로 연다.
- 비밀값은 Action 입력으로 받지 않는다. 콘솔이 입력받은 키는 macOS Keychain을 우선 사용하고, 사용할 수 없으면 데이터 폴더의 0600 파일에 저장한다. Action에는 `keychain:` 또는 `file:` 참조만 넘기며 값은 응답·로그·변경 기록에 남지 않는다.
- 모든 상태 변경 Action은 변경 기록(`audit.list`)에 경로·결과·설정 버전과 함께 남고, 값은 안전한 필드만 남긴다.
