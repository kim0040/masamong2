## Capture provenance

Captured on **2026-10-02** from the current checkout: 30 published desktop screenshots, covering six views per locale (`setup`, `home`, `lab`, `memory`, `room`, `tools`) for English (`en`), Korean (`ko`), Japanese (`ja`), Simplified Chinese (`zh-Hans`) and Spanish (`es`). The five standard views are 1440 × 1000; the answer lab is 1440 × 1100 so its composer remains visible. The console ran as an isolated local instance bound to loopback. Practice mode used synthetic sample fixtures and an offline mock model; no live service or external API was called. A separate set of 30 mobile QA captures uses a 320 × 800 viewport and is not included in this README gallery.

The console labels and synthetic sample text follow the selected locale. Canonical platform names, brand names, stable IDs and model identifiers may retain their original spelling where they are identifiers or proper names. These screenshots document localized UI and fixtures; they do not demonstrate live model fluency.

For asset handling and localization conventions, see [brand assets](../../brand-assets.md), [tools and languages](../../tools-and-languages.md) and [console locale guidance](../../../locales/ui/README.md).
