# 언어 설정

**한국어** | [English](https://github.com/kim0040/masamong2/wiki/Languages)

마사몽에는 서로 다른 세 가지 "언어"가 있습니다.

| 무엇 | 정하는 곳 | 영향 |
|---|---|---|
| **답변 언어** | 채널 말투(`persona_ref`) → 서버 `guilds.<id>.locale` → `i18n.default_locale` | 프롬프트, 답변, 도구 설명, 거절 메시지, Discord 카드 문구 |
| **기억 언어** | `memory.languages` (기본 `[ko]`) | 검색용 토크나이저, 조사·대명사·불용어 처리, 요약 프롬프트 |
| **콘솔 언어** | 콘솔 **화면 → 언어** | 관리 화면 문구 (한국어·영어·일본어·중국어(간체)·스페인어 내장) |

## 답변 언어 바꾸기

첫 설정 마법사가 봇이 답할 언어를 묻고(콘솔 언어가 기본으로 제안됩니다) `i18n.default_locale`로 저장합니다. 나중에는 설정에서 바꿉니다.

```bash
masamong channels configure --guild_id G --id C --persona_ref friendly_en   # 이 채널은 영어로
```

내장 말투는 `friendly_ko`(한국어 반말), `warm_ko`(한국어 존댓말), `friendly_en`(영어), `friendly_ja`·`warm_ja`(일본어 반말·정중어), `friendly_zh_hans`(중국어 간체), `friendly_es`(스페인어) 등이 있고, `personas`에 직접 추가할 수 있습니다([설정 레퍼런스](https://github.com/kim0040/masamong2/wiki/설정-레퍼런스)). 봇 이름은 `instance.bot_names`에서 바꿉니다.

말투를 고르지 않은 방은 그 방 언어(서버 `guilds.<id>.locale` → `i18n.default_locale`)의 기본 말투를 씁니다.

| 언어 | 기본 말투 | 어조 |
|---|---|---|
| 한국어 | `warm_ko` | 다정한 존댓말(해요체). 여전히 "방의 친구" |
| 일본어 | `warm_ja` | 다정한 정중어(です・ます). 처음 보는 사람에게 반말을 쓰지 않음 |
| 영어·스페인어·중국어(간체) | `friendly_<tag>` | 편한 말투 하나(스페인어는 *tú*) |

그 밖에는 `friendly_<tag>`, 그다음 `friendly_en`, 그다음 `friendly_ko`로 내려갑니다. 반말 프리셋인 `friendly_ko`와 `friendly_ja`는 방마다 고를 수 있게 그대로 있습니다(말투 화면에서 반말 프리셋으로 표시됩니다). 한국어·영어·일본어·중국어(간체)·스페인어 기본 말투는 친근한·정중한·짧은·다정한 네 가지이고, 기본 제공 말투는 콘솔에서 삭제 대신 숨겼다가 되돌릴 수 있습니다. 말투 화면은 화면·시스템 언어를 자동으로 따르고, 관리자별 수동 선택은 기억되며, 어느 말투가 기본인지 표시해 줍니다.

**기본이 존댓말인지 반말인지.** 존댓말 기본은 `i18n.polite_default` 설정(**설정 → 새 방은 존댓말로 시작**)이 정합니다. 지금 새로 만든 인스턴스는 켜져 있고, **이 설정이 생기기 전에 만든 인스턴스는 꺼져 있습니다.** 그래서 업그레이드해도 말투를 정한 적 없는 방의 말투는 바뀌지 않고, 켤 때까지 이전처럼 답합니다. 설정을 켠 채로 반말을 유지하려면 `warm_ko`·`warm_ja`를 숨기세요(`personas.warm_ko.hidden: true` 또는 말투 화면의 숨기기 버튼). 그러면 방이 `friendly_ko`·`friendly_ja`로 내려갑니다. 말투를 직접 고른 방은 영향을 받지 않습니다.

**어디서나 같은 말투.** 아침 운세 DM과 별자리 운세는 그 언어 기본 말투와 같은 어조(한국어 해요체, 일본어 です・ます)로 말하고, `/summary` 게시글은 `#` 제목이나 표 없이 굵은 소제목과 한 단계 글머리표만 씁니다. Discord에서 글자 그대로 보이는 표시를 피하기 위해서입니다. 반말 프리셋 `friendly_ko`를 고른 방도 운세는 해요체로 받습니다.

## 기억 언어

여러 언어가 섞인 방이면(예: 한국어와 영어) `memory.languages: [ko, en]`처럼 여러 개를 지정합니다. 색인은 시작할 때 메모리에서 다시 만들므로 바꿔도 재임베딩은 필요 없습니다.

## 새 언어 추가

봇 언어팩, 운영·Discord 문구, 콘솔 문구는 **따로 번역**합니다.

| 번역 대상 | 파일 |
|---|---|
| 봇 프롬프트·검색 규칙 | `internal/lang/packs/<tag>.json` (기준: `en.json`) |
| Discord 명령·결과 카드·오류 문구 | `locales/<tag>.json` (기준: `locales/en.json`) |
| 관리 콘솔 (한국어·영어 1차, 그 밖의 언어는 번들) | `internal/transport/web/ui/scripts/strings.py` (수정 후 `python3 scripts/strings.py` 실행) |
| 관리 콘솔 (추가 언어) | `locales/ui/<tag>.json` (`locales/ui/README.md` 참고). 콘솔의 언어 묶음은 프로그램에 내장되므로 새 언어는 다시 빌드한 뒤에야 나타납니다(`make ui` 후 프로그램 빌드) |
| 카카오톡 내보내기 표시 문구 | `internal/memory/corpus/markers/<tag>.json` (다른 언어 카카오톡에서 내보낸 경우만) |

주의할 점:

- `{bot}`, `{name}` 같은 **자리표시자의 이름과 개수를 그대로** 둡니다.
- 플래너 JSON 예시의 키·타입, 도구 ID는 번역하지 않습니다.
- 조사·대명사·불용어, 명령 별칭은 직역하지 말고 그 언어에 맞게 새로 정합니다.
- 원문 대화·사용자 ID·키를 외부 번역기에 보내지 않습니다.

검증:

```bash
cd internal/transport/web/ui && npm run test:i18n && npm run check -- --fail-on-warnings && cd -
make ui
go test ./internal/i18n ./internal/lang ./internal/transport/web
go test ./...
```

자세한 절차는 저장소의 [docs/tools-and-languages.md](https://github.com/kim0040/masamong2/blob/main/docs/tools-and-languages.md)에 있습니다.
