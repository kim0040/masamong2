## What's new

- A search for papers or studies uses each service's own paper search. For recent papers it keeps the recent years.
- Official notices are no longer treated as news, and words like paperclip no longer start a search for papers.
- Fixed: the bot's own name no longer ends up in the search words, even a name of several words or one in quotes.
- Search results that are copies of one page on the same site are shown once.

## For operators

- Each service searches papers its own way: Exa and TinyFish by paper category, Serper with Google Scholar, Tavily with preferred scholarly sites.
- Search cost: a request whose answer was lost, cut short by the end of the turn or unreadable is charged.
- Search cost: an HTTP error answer is never charged, even when its body was too large or cut off.

## 새 기능과 수정

- 논문이나 연구를 찾을 때는 서비스마다 가진 논문 검색을 쓰고, 최근 논문이면 최근 연도만 남깁니다.
- 공식 공지는 더 이상 뉴스로 보지 않고, paperclip 같은 단어가 논문 검색을 시작하지도 않습니다.
- 수정: 봇의 이름이 검색어에 들어가지 않습니다. 여러 단어로 된 이름이나 따옴표 안의 이름도 뺍니다.
- 같은 사이트에서 한 페이지를 복사한 검색 결과는 한 번만 보여 줍니다.

## 운영자용

- 서비스마다 논문 검색 방식이 다릅니다: Exa와 TinyFish는 논문 분류, Serper는 Google Scholar, Tavily는 학술 사이트 우선.
- 검색 비용: 답을 잃었거나, 턴이 끝나 끊겼거나, 읽을 수 없던 요청은 차감합니다.
- 검색 비용: HTTP 오류 응답은 본문이 너무 크거나 끊겨도 차감하지 않습니다.
