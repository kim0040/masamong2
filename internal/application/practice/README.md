Sample conversations for the console's offline practice mode (`internal/application/practice.go`).
The English, Japanese, Simplified Chinese and Spanish files tell the same fictional story: four friends
plan a camping trip, celebrate a birthday, arrange a hike and beach trip, then talk about a book and a
move. Each file has the same 42 messages and the same CSV columns. The Korean sample is a separate,
naturally localized fictional conversation.

Every name, place and event is invented for this purpose. These samples are imported into the separate
practice instance (`<data-root>/practice`) only; they are never imported into a real instance.
